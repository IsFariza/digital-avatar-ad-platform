# Existing Digital Avatar Platforms Comparison

## 1. Introduction

The purpose of this comparison is to examine existing digital avatar platforms and identify useful technologies and workflows for our diploma project.

Four platforms were selected:
1. Synthesia
2. HeyGen
3. D-ID
4. Colossyan

The comparison is based on previously examined developer documentation.

It does not represent an independent performance test.

## 2. Comparison Criteria

Eight criteria were selected:

1. Video generation input
2. Reusable templates
3. Avatar selection
4. Language and translation support
5. Background generation status
6. Completion notifications
7. Video result access
8. Campaign and review history

## 3. Synthesia

Synthesia provides documented avatar video generation using scripts and templates.

Relevant documented functions:
- Script or template input
- Avatar videos
- Video translation
- Background task status
- Completion and failure webhooks
- Video result links

The reviewed documentation did not establish an integrated campaign and audience record with review history.

## 4. HeyGen

HeyGen provides documented video generation and translation tools.

Relevant documented functions:
- Script input
- Template variables
- Avatar identifiers
- Translation features
- Video status checking
- Completion callbacks
- Download links

The reviewed documentation did not establish the complete campaign review workflow considered in our project.

## 5. D-ID

D-ID provides documented talking-avatar generation using images and text or audio.

Relevant documented functions:
- Source image input
- Text or audio scripts
- Talking-avatar generation
- Talk status retrieval
- Webhook parameters
- Result retrieval

Reusable templates and translation functions were not established by the reviewed documentation.

This does not mean these functions are necessarily unavailable.

## 6. Colossyan

Colossyan provides documented video generation through templates and actor selection.

Relevant documented functions:
- Template variables
- Actor selection
- Multiple languages
- Video job status
- Completion callbacks
- Generated video links

Its documented functions provide useful examples for the proposed system workflow.

## 7. Comparison Summary

| Criterion | Synthesia | HeyGen | D-ID | Colossyan |
|---|---|---|---|---|
| Script or input | Yes | Yes | Yes | Yes |
| Reusable template | Yes | Yes | Not established | Yes |
| Avatar selection | Yes | Yes | Yes | Yes |
| Translation | Yes | Yes | Not established | Multiple languages documented |
| Status tracking | Yes | Yes | Yes | Yes |
| Completion notification | Yes | Yes | Webhook parameter | Yes |
| Result access | Yes | Yes | Yes | Yes |
| Campaign review history | Not established | Not established | Not established | Not established |

"Not established" means the reviewed documentation did not confirm the function. It does not mean the platform cannot provide it.

## 8. Implications for Our Project

Existing platforms already provide important video generation functions.

Our project will investigate a workflow that connects:
- Advertising campaign briefs
- Editable content
- Audience and language variants
- Human approval
- Video generation
- Result review

The project does not claim that these functions are absent from existing competitors.

## 9. Limitations

The comparison does not include direct quality measurements.

Paid account access, generation costs, language suitability and service restrictions still need verification.

## 10. Conclusion

The comparison helped identify useful design patterns for the proposed digital avatar platform.

The next step is to evaluate provider access, cost and technical suitability before selecting a video generation service.
